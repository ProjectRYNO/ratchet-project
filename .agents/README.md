# AI contributor resources

All substantive AI instructions, guides, and skills live here. The root
`AGENTS.md`, `CLAUDE.md`, and `.github/copilot-instructions.md` are discovery
pointers for assistants that look in those conventional locations.

| Resource | Purpose |
| --- | --- |
| [INSTRUCTIONS.md](INSTRUCTIONS.md) | Main rule set for every game |
| [guides/GAME_WORKFLOW.md](guides/GAME_WORKFLOW.md) | Matching policy and bringing up another game |
| [guides/DEADLOCKED.md](guides/DEADLOCKED.md) | Deadlocked setup, build/test commands, and clean-build workflow |
| [skills/ryno-decompile/SKILL.md](skills/ryno-decompile/SKILL.md) | Function recovery and fixed-address placement |
| [skills/ryno-symbols-types/SKILL.md](skills/ryno-symbols-types/SKILL.md) | Global symbols, struct layouts, and headers |
| [skills/ryno-build-verify/SKILL.md](skills/ryno-build-verify/SKILL.md) | Compilation, audits, troubleshooting, and ISO verification |

Assistants without skill support can read the corresponding SKILL.md directly.
Shared technical documentation starts at [docs/README.md](../docs/README.md).

Use [templates/HANDOFF.md](templates/HANDOFF.md) for a resumable task summary.
The [verification command](../docs/build/VERIFICATION.md) and
[decision log](../docs/decompilation/DECISIONS.md) keep results and rationale consistent.
